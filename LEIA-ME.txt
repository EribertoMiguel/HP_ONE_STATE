SISTEMA DE TRIAGEM MÉDICA RP — ARQUIVOS SEPARADOS
===================================================

Arquivos:
- triagem_medica_rp.py : servidor local Python
- index.html            : estrutura da página
- style.css             : estilos e layout visual
- script.js             : navegação, sintomas, resumo e exportação

IMPORTANTE:
Mantenha os quatro arquivos na mesma pasta. Os caminhos do CSS e JavaScript
são relativos, então index.html também pode ser aberto diretamente no navegador.
Para usar o sistema pelo servidor Python, siga os passos abaixo.

Como executar com Python:
1. Instale Python 3, se ainda não estiver instalado.
2. Abra a pasta no Explorador de Arquivos.
3. Digite cmd na barra de endereço e pressione Enter.
4. Execute: python triagem_medica_rp.py
5. O navegador abrirá em http://127.0.0.1:8000
6. Para encerrar, volte ao terminal e pressione Ctrl+C.

Não é necessário instalar bibliotecas extras.
Uso exclusivo para simulação de roleplay; não é prontuário clínico real.
